# Security

Please report a security problem in the WizMessage MCP server to info@bethtechnologies.com. Do not open a public issue, and do not include a key, a password or a customer's phone number.

WizMessage keys start with `pk_live_` and are secret. If a key may have been seen by somebody else, open **AI Agents (MCP)** in WizMessage, press Pause at once, then delete the agent and connect a new one.
